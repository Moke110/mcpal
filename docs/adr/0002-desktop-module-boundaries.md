# 由桌面启动入口装配六个模块

现有桌面实现把界面、会话和模型适配放在 `src/desktop/`。聊天闭环需要能独立替换输入、模型和输出，同时复用现有 Electron 应用和 IPC 边界。

在 `src/` 下设置 `gui/`、`sensor/`、`processor/`、`memory/`、`expressor/` 和 `controller/`。Electron 主进程的启动入口负责装配。GUI 通过 IPC 提交输入和接收输出。感受器与表达器通过装配时传入的接口连接，处理器可以脱离 Electron 运行。记忆和控制器仅预留目录，职责待定。

相比沿用按桌面运行环境归集的目录，按职责划分能明确输入、推理和输出的依赖，并允许独立替换各端。现有创建伙伴、聊天、陪玩、真实模型和音频入口继续可用。

本次部署验收使用 GUI 文本输入、感受器、模拟模型、表达器和 GUI 聊天面板。全双工行为留待后续决定。
