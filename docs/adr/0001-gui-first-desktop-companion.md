# 先交付桌面界面并用它验收伙伴功能

已通过验证的 Mineflayer I/O 是桌面伙伴的一期基础。我们先交付能在模拟模式下运行的 Electron 界面，再从同一个界面验证真实 Minecraft、模型和音频能力，让操作者在账号、设备或模型尚未配置时仍可体验交互和看到失败状态。

对话使用可切换的 API 和本地推理后端。语音由本机 CPU 语音识别和语音合成提供。GUI、可信 Minecraft 聊天和本机语音识别是一期的三个入口，GUI、Minecraft 发言和本机语音合成是三个出口。KOOK 连接排到一期之后。

详见[一期桌面设计](../architecture.md#一期桌面设计)和[一期交付顺序](../roadmap.md#桌面伙伴一期)。
